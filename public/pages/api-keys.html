Správa API klíčů

Zde můžete spravovat své API klíče pro přístup k mapovým službám.

Co jsou API klíče?

API klíče vám umožňují přístup k různým mapovým službám, jako je Google Maps, OpenRouteService, Mapy.cz a další. Tyto služby poskytují funkce jako vyhledávání míst, plánování tras, zobrazení map a další.

Proč potřebuji API klíče?

Mapové služby obvykle vyžadují API klíče pro přístup k jejich funkcím. Tyto klíče jsou obvykle zpoplatněné, ale my vám nabízíme možnost zakoupit si je za výhodné ceny. Zakoupením API klíče získáte přístup k funkcím, které by jinak byly nedostupné nebo drahé.

Jak to funguje?

1. Vyberte si plán API klíče, který odpovídá vašim potřebám.

2. Zaplaťte za klíč pomocí platební karty.

3. Po úspěšné platbě bude váš API klíč aktivován a můžete ho začít používat.

4. API klíč je platný po dobu uvedenou v plánu a má omezený počet požadavků (pokud je uvedeno).
