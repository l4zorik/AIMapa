AIMapa - Testovací stránka

Tato stránka slouží k testování různých funkcí aplikace AIMapa verze 0.3.8.5.

Otevřít aplikaci Spustit testy v prohlížeči GitHub repozitář

Unit testy

Testy pro ověření jednotlivých komponent a funkcí.

Unit testy ověřují správnou funkčnost jednotlivých komponent aplikace:

  • Výpočet vzdálenosti mezi body
  • Parsování souřadnic
  • Validace souřadnic

Pro spuštění testů z příkazové řádky použijte:

npm run test:unit

Integrační testy

Testy pro ověření interakce mezi moduly a externími API.

Integrační testy ověřují správnou interakci s externími API:

  • OpenStreetMap API
  • Google Maps API
  • Vyhledávání tras
  • Multimodální vyhledávání

Pro spuštění testů z příkazové řádky použijte:

npm run test:integration

End-to-end testy

Testy pro ověření celého workflow aplikace.

End-to-end testy ověřují celý workflow aplikace:

  • Vyhledání trasy mezi dvěma body
  • Vyhledání bodu zájmu a přidání do oblíbených
  • Změna mapového podkladu a přepnutí do glóbus režimu
  • Interakce s AI asistentem pro doporučení trasy

Pro spuštění testů z příkazové řádky použijte:

npm run test:e2e

AI model testy

Testy pro ověření AI modelu a jeho výkonu.

AI model testy ověřují výkon AI modelu:

  • Klasifikace míst (Accuracy, Precision, Recall, F1-score)
  • Predikce času cesty (MAE, RMSE, R²)
  • Doporučení míst (Precision@k, NDCG)
  • Bias a fairness (Equal Opportunity, Statistical Parity)

Pro spuštění testů z příkazové řádky použijte:

npm run test:ai

Všechny testy

Spuštění všech testů najednou.

Pro spuštění všech testů z příkazové řádky použijte:

npm test

Nebo použijte skripty:

  • Linux/macOS: ./tests/run-tests.sh --all
  • Windows: tests\run-tests.bat --all
