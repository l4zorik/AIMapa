|--------|--------|-------------|

### 🗺️ Mapa
| Funkce | Klávesa | Hlasový příkaz |
|--------|---------|----------------|
| Přiblížit | `+` | "přiblíž" |
| Oddálit | `-` | "oddal" |
| Fullscreen | `F11` | "fullscreen" |
| 3D režim | `G` | "glóbus" |
